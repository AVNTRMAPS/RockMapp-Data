# RockMapp Data

Public distribution repository for downloadable RockMapp data products.

This repository is used for versioned RockMapp data releases, manifests, checksums, source metadata, and attribution required for anonymous application downloads. Application source code is not distributed from this repository.

Data products may be derived from public or redistributable sources including U.S. Geological Survey, Bureau of Land Management, Colorado Geological Survey, OpenStreetMap/Protomaps, and other documented sources. Individual releases include the relevant provenance, limitations, and integrity metadata.

RockMapp data is a research aid. It does not determine land ownership, legal access, mining-claim validity, collecting permission, hazards, or field safety.
